# 私立医院门诊管理系统

## How to Run

```bash
# 1. 克隆项目
git clone <repository-url>
cd label-02506-main

# 2. 启动所有服务
docker-compose up --build -d

# 3. 查看服务状态
docker-compose ps

# 4. 查看日志
docker-compose logs -f backend

# 5. 停止服务
docker-compose down
```

首次启动需要等待 MySQL 初始化完成（约30秒），然后访问系统。

## 题目内容

我计划开发一个 私立医院门诊管理系统 ，用于小型私立门诊的日常运营管理，具体诉求如下：

一、项目核心定位
适用场景：小型私立门诊（无住院、体检等复杂业务），聚焦 "挂号 - 就诊 - 处方 - 缴费 - 取药" 的门诊核心闭环；
角色划分：仅 2 类角色（医生 = 系统管理员，负责全流程管理；病人 = 普通用户，仅操作个人相关功能）；
核心目标：功能简易实用、落地性强，满足门诊日常运营需求，同时降低开发难度。

二、技术栈选型（已确定）
后端：Spring Boot（核心框架）；
前端：HTML + CSS + JavaScript（基础前端技术，无需复杂框架，如 Vue/React）+ 简单 UI 组件（如 Bootstrap，可选）；
数据库：MySQL（存储病人信息、挂号记录、处方、药品等数据）；
辅助工具：EasyExcel（实现数据导出）、JSP/Thymeleaf（页面渲染，二选一即可）。

三、核心功能需求（7 个核心模块）
病人档案管理模块 ：医生可建档、维护、检索、导出档案；病人可查看并补充个人信息；
门诊挂号管理模块 ：医生可设置挂号规则、手动挂号 / 取消；病人可在线挂号、查看 / 取消个人挂号；
就诊诊疗模块 ：医生可接诊、录入病历、标记复诊；病人可查看个人病历和复诊提醒；
处方管理模块 ：医生可开具、审核、查询、打印处方；病人可查看并打印个人电子处方；
药品管理模块（简易版） ：医生可录入药品信息、维护库存、设置低库存预警；病人可查看处方内药品详情；
缴费管理模块 ：医生可核算费用、录入缴费记录、登记欠费；病人可查看个人缴费明细和欠费记录；
数据统计模块（医生专属） ：医生可统计就诊量、挂号量、药品销量、营收等，支持报表导出；病人无权限。

## 项目介绍

本系统是一个面向小型私立门诊的日常运营管理系统，实现了门诊核心业务闭环。

### 技术架构

- **后端**：Spring Boot 3.4.2 + Spring Security + Spring Data JPA
- **前端**：Thymeleaf + Bootstrap 5
- **数据库**：MySQL 8.0
- **容器化**：Docker + Docker Compose

### 功能模块

1. **用户认证**：登录、注册、权限控制
2. **病人档案管理**：建档、维护、检索、导出 Excel
3. **门诊挂号管理**：在线挂号、现场挂号、排班规则管理
4. **就诊诊疗**：接诊、病历录入、复诊提醒
5. **处方管理**：开具处方、审核、发药、打印
6. **药品管理**：库存管理、低库存预警
7. **缴费管理**：费用核算、录入缴费、登记欠费
8. **数据统计**：就诊量、营收统计、报表导出

### 系统特性

- **现代化 UI**：深色科技感登录页、响应式布局、渐变主题色
- **完整业务闭环**：挂号 → 就诊 → 处方 → 缴费 → 取药
- **全局异常处理**：统一错误响应、友好错误页面
- **安全规范**：POST 方式登出、权限隔离
